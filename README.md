# Whisper GPU для NVIDIA 535

Wyoming Faster Whisper для Home Assistant с изменяемым `initial_prompt`.
Wyoming работает на TCP `10300`; отдельный HTTP API промпта — на `10301`.
Модель остаётся загруженной: изменение подсказки не перезапускает контейнер.

## Установка / обновление

1. Обновите файлы этого репозитория. Сохраните существующую папку `data`.
2. При необходимости авторизации скопируйте `.env.example` в `.env` и задайте `WHISPER_PROMPT_TOKEN`. Без токена этот шаг можно пропустить.
   Сгенерировать значение можно командой `openssl rand -hex 32`.
   В `.env` записывается сам токен, без `Bearer`; файл исключён из Git.
3. Один раз пересоберите и запустите контейнер:

   ```sh
   docker compose up -d --build
   ```

4. В HA Dialog UI откройте «Команды → Промпт распознавания».
   Укажите `http://АДРЕС_ХОСТА_WHISPER:10301` и токен, если он задан в контейнере.
   Если HA работает в другом контейнере, `localhost` указывает на сам HA,
   а не на Whisper: используйте доступный ему адрес хоста.
5. Введите текст промпта и нажмите «Сохранить и применить».

После первой пересборки последующие изменения промпта не требуют перезапуска.
Порт `10301` должен быть доступен из Home Assistant; оставьте его в доверенной
сети или используйте HTTPS через свой reverse proxy, не публикуйте в интернете.
Если `WHISPER_PROMPT_TOKEN` задан, API требует `Authorization: Bearer <WHISPER_PROMPT_TOKEN>`.
Если переменная отсутствует или пуста, API работает без проверки авторизации.

## Хранение и применение

- Начальная подсказка берётся из `default-initial-prompt.txt` в образе.
- После первого сохранения используется `/data/initial-prompt.json`.
- Папка `./data:/data` сохраняет промпт между пересозданиями контейнера.
- Пустая строка отключает подсказку; максимум — 16000 символов.
- Запись атомарная. Если файл не удалось сохранить, активный текст не меняется.
- Новое значение читается при вызове транскрипции. Уже запущенная транскрипция
  может завершиться с предыдущим промптом.
- `initial_prompt` подсказывает словарь и стиль речи; это не инструкция LLM
  и не гарантия точного распознавания. Whisper использует ограниченный контекст,
  поэтому короткий список нужных слов и фраз полезнее большого текста.
- Управляемый промпт заменяет CLI `--initial-prompt`; не добавляйте этот параметр
  обратно в Compose. Не редактируйте JSON вручную во время работы: используйте API.

## API

`GET /initial-prompt` возвращает `{"initial_prompt":"..."}`.

`PUT /initial-prompt` принимает список фраз (или строку):

```json
{"initial_prompt":["Насыпь еды", "Запусти пылесос", "Включи свет в коридоре"]}
```

Успех: `{"initial_prompt":"...", "applied":true}`. Ошибки: `401` — токен,
`400` — неверный JSON или промпт, `413` — размер тела, `500` — ошибка хранения.
Промпты и токены не выводятся в журнал доступа этого API.

## Версии и проверка

Сохранена база CUDA 12.2 / cuDNN 8. Для неё закреплён `ctranslate2==4.4.0`;
`wyoming-faster-whisper==3.8.1` закреплён, потому что обёртка использует
свойство `ModelLoader.initial_prompt` этой версии. При обновлении пакета
нужно заново проверить чтение этого свойства при каждой транскрипции.

```sh
python -m unittest -q test_prompt_runtime
docker compose config --quiet
```

Автоматические тесты проверяют API, авторизацию, живое обновление уже созданного
обработчика и восстановление из файла. Реальные CUDA-модель, драйвер 535,
аудиораспознавание и доступность сервера из HA требуют проверки на вашем хосте.
